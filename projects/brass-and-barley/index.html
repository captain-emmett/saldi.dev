The idea

Make the pieces
feel connected.

Brass & Barley is a personal Minecraft build centered on Create machinery, farming, animal care, and brewing. A workshop can support a farm, the farm can supply a kitchen, and those systems can grow into a larger home.

The work is in choosing compatible mods, adjusting their settings, and explaining how they fit together. An in-game guide offers suggestions while leaving every chapter available from the start.

Technical scope

Configuration
and compatibility.

Pack foundation: Minecraft 1.21.1, NeoForge, and a curated mod set around Create, Farmer's Delight, seasons, husbandry, and brewing.

Build tooling: PowerShell scripts assemble the pack, generate the FTB quest guide from JSON, and regenerate a data-only compatibility patch.

Player guide: seven chapters and 34 short entries, with optional checkmarks and item tasks that do not consume the item. Stable IDs let text changes preserve quest completion.

Maintenance: pinned dependencies, documented configuration choices, recoverable backups, startup checks, and a list of remaining gameplay tests.

Hardware & runtime

A computer,
not a custom device.

Runs on a computer with Minecraft, the Prism Launcher, and Java 21. The local instance is configured with a 4 GB minimum and 8 GB maximum Java heap; these are instance settings rather than measured minimum system requirements.

This is a software configuration project with no dedicated electronics or custom hardware build.

Development notes

Guide / compatibility / testing
Development note

Moving the guide into FTB Quests

The guide moved from a page-based ledger to short, scrollable FTB Quests notes. Chapters cover settling in, Create machinery, food and seasons, husbandry, home and field gear, airships, and exploration conveniences. There are no reward items or progression gates.

Development note

Keeping compatibility fixes reproducible

A data-only patch adds item-existence conditions to optional Create Connected loot entries and replaces an invalid Copycats physics selector with an optional block tag. A PowerShell script regenerates the patch while leaving the original mod archives intact.

Development note

Separating startup checks from gameplay checks

Documented validation reached the title screen and checked video settings, including a successful Photon shader compilation. In-world checks for Create and Aeronautics rendering, airship cargo, distant terrain, and save/reload behavior remain part of the test plan.

The reusable pack template keeps shaders disabled pending those in-world checks.
