The idea

Understand what
the code is doing.

This collection comes from my undergraduate programming coursework at the University of Hawaiʻi at Mānoa. Command-line programs gave me practice with the structures and memory behind an application.

The work covers modular C and object-oriented C++, including linked data structures, classes, inheritance, iterators, and persistent storage.

Technical scope

Data, memory,
and program structure.

Data structures: linked structures and iterators for organizing and moving through data.

Program design: modular C, C++ classes, and inheritance.

Memory and storage: pointers, dynamic memory, binary data, and information saved between program runs.

Debugging: compiler warnings and test cases to work through pointer behavior, input handling, and file data.

Hardware

A software
learning project.

Runs on a computer with a C/C++ development environment and a terminal. These assignments do not use a dedicated hardware build or external electronic components.

Development notes

Coursework / 2024–2025
Coursework note

Working with memory

Pointer use and dynamic memory were central parts of the coursework. Compiler warnings and test cases helped me reason through how data was allocated, accessed, and changed.

Coursework note

Structuring programs

Modular C and object-oriented C++ provided different ways to organize a program. Linked structures, classes, inheritance, and iterators connected those design choices to the data being stored.

Coursework note

Handling input and saved data

Command-line input and persistent binary storage added another layer of debugging: tracing how information moved into the program and how it was represented in a file.
