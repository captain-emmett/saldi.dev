Fantasy Draft
Command Center

A draft-day workspace for tracking picks, comparing available players, and keeping a fantasy-football roster organized.

Open the app ↗

The idea

Keep draft day
in one place.

The Command Center combines a player board, draft log, targets, notes, and roster view in a browser app. As players are drafted, it tracks the current pick and upcoming turns, while the roster view shows open positions and bye-week overlap.

The app works on desktop and mobile, saves the draft in the current browser, and can be added to a phone's home screen.

Technical scope

A small app
with a saved state.

Interface: responsive HTML and CSS with JavaScript for filtering players, logging picks, tracking roster needs, and adjusting league settings.

Draft logic: supports snake and linear draft order, selectable scoring, targets, and recommendations based on ranking, roster needs, scarcity, bye weeks, and draft strategy.

Persistence: local browser storage saves draft state. JSON export/import moves it between devices; CSV export provides a draft log.

Offline support: a service worker caches the app after the first successful visit. The static app uses bundled player data and has no server or database.

Hardware

Use the device
already with you.

Runs in a browser on a computer, tablet, or phone. There is no dedicated hardware build or external electronic component list.

An initial online visit fills the offline cache. Drafts are saved on the current browser and device; JSON export/import provides a manual way to transfer them.

Development notes

Interface / state / offline use
Development note

Connecting the board to the roster

Recording a pick updates player availability, the draft log, upcoming turns, and roster needs. Recommendations consider the user's roster and chosen strategy alongside the bundled player rankings.

Player data is a saved 2026 snapshot. The app does not fetch live rankings or act as a projection model.

Development note

Keeping the draft available

Browser storage preserves picks, targets, notes, and settings between visits. JSON backups provide a separate copy and a way to move the draft to another browser or device.

Development note

Packaging for desktop and mobile

A web app manifest and service worker support home-screen installation and offline use after the first load. The portfolio hosts the app at its own address so the résumé and draft workspace can be opened separately.
